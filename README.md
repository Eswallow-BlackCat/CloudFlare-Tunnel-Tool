# CF隧道控制台 —— Cloudflare Tunnel 回源优选域名快速切换工具

> 版本 **1.0.0**｜纯 Python 标准库实现，零第三方依赖｜CLI + 本地网页控制台

## 快速开始（从零到跑通）


前置条件:CloudFlare上已有两个托管域名，一个主访问域名，一个辅助加速域名(可用免费域名)
```bash
# 1.启动本地控制台（首次运行不需要任何配置文件）
./cfopt.sh web --port 8787 --key "你的访问密钥"
# 2.浏览器打开控制台 → 设置页填 Cloudflare API 令牌 → 保存
# 3.进「一键配置」：选隧道 → 选入口 zone / 加速 zone → 开始配置并验证
```

零第三方依赖（Python 3.11+ 标准库）。**配置文件里不预置任何域名/主机名/优选域名**：只填令牌，其余全部从账户里自动拉取；
而且**拉取结果也不写盘**（只在进程内存里用），磁盘上可以完全没有域名和令牌。
自带链路体检、自动回滚、实测择优、跨账户双令牌。

---

### 它解决什么问题?

Cloudflare Tunnel 省掉了源站公网 IP，但国内访问默认 Cloudflare 节点常常绕路。所谓“回源优选”，就是让客户端解析到**对你这条线路最快的 Cloudflare 边缘 IP**，再靠边缘把请求送回 Tunnel。

代价是：主域名的 CNAME 要经常换成当前最快的「优选域名」。手工在控制台点来点去的问题——慢、容易点错 zone、切完不知道有没有生效、切坏了不知道怎么退回去。

### 1.0.0

**CF隧道控制台**。

* 一键配置向导：新建/选择 Tunnel → 拉取令牌下的域名 → 选入口与加速 zone（自动加前缀）→ 优选池实测择优 → 写入并体检 → 失败回滚；
* DCV 委派：优先用 `_acme-challenge` CNAME 委派（token 轮换交给 Cloudflare），TXT 与之共存互为保险；
* 一键清除 Cloudflare 加速配置：自定义主机名 / 回退源 / 回源与入口记录 / TXT 与委派 CNAME 全部清掉，幂等可重复执行；
* 可视化控制台：控制台 / 设置 / 一键配置三页，令牌权限清单 + 只读实测，SSE 流式日志；
* 令牌权限：`Zone:Read`、`DNS:Edit`、`SSL and Certificates:Edit`、`Cloudflare Tunnel:Read`；
* 纯标准库实现（Python 3.11+），零第三方依赖；244 个用例覆盖 CLI 与 Web。
